# v2ray-pool

مخزن موتور هوشمند V2Ray Pool است: یک فرایند دسته‌ای برای دریافت منابع عمومیِ مجاز، تجزیه و اعتبارسنجی کانفیگ‌ها، آزمون کنترل‌شده با Xray، ثبت شواهد IP خروجی، رتبه‌بندی بر پایه اندازه‌گیری واقعی و تولید اشتراک‌ها و API استاتیک.

## معماری

جریان اصلی داده چنین است:

`Sources → Collector → Parser / Normalizer / Deduplicator → Validator → Xray Tester → IP Intelligence → Ranking → Distribution → Quality Gate → Publisher`

## وضعیت ایمن پیش‌فرض

این مخزن برای بازبینی محلی و اعتبارسنجی CI آماده شده، اما هنوز برای اجرای تولیدی تأیید نشده است. فهرست منابع در `config/sources.yml` خالی است؛ آزمون Xray در `config/settings.yml` غیرفعال است؛ انتشار URI خام نیز به‌طور پیش‌فرض خاموش است. بنابراین داده یا عملکرد زنده‌ای را نباید از خروجی فعلی استنباط کرد.

پیش از اجرای تولیدی باید فقط منابع دارای اجازه روشن برای بازتوزیع اضافه شوند، باینری و هش معتبر Xray تنظیم و بررسی شوند، شاخه جداگانه `data` ایجاد و محافظت شود، آزمون‌های محیط واقعی انجام شوند و خروجی عمومی بازبینی شود. GitHub-hosted runners محل جغرافیایی ثابتی برای آزمون تضمین نمی‌کنند. مستند [آمادگی انتشار](docs/RELEASE-READINESS.md) این موانع را فهرست می‌کند.

## توسعه محلی

نیازمندی: Python 3.11 یا جدیدتر.

```bash
python -m pip install -e ".[dev]"
python -m engine.cli validate-settings
pytest
```

برای جزئیات مراحل آزمون، تنظیمات و عملیات، به `docs/14-testing.md` و `docs/15-operations.md` مراجعه کنید. اسکریپت نصب Xray و گردش‌کارهای انتشار باید فقط پس از بررسی هشدارهای امنیتی و تکمیل پیش‌نیازهای تولیدی استفاده شوند.

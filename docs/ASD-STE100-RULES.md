# Controlled English Rules

Project manuals use an ASD-STE100-oriented writing style.

1. Use short sentences.
2. Use one instruction in each step.
3. Use active voice.
4. Use the same term for the same component.
5. Use a direct command for a required action.
6. Define an abbreviation before first use.
7. Avoid idioms and informal expressions.
8. Avoid vague words such as `fast`, `safe`, or `good` without a measurable definition.
9. State a warning before a hazardous action.
10. Separate a confirmed result from an assumption or an open decision.

This project does not claim formal ASD-STE100 certification. A qualified technical publications review is required for formal compliance.
